# G3 — 发布、索引、增长和运营

## 分支和部署

- `feature/fix` 做更改 → 测试 → noindex/disallow 预览环境 → 浏览器检查 → 经过批准的 release 分支 → 构建生产包 → 生产部署。
- 核对 Git commit 与 Cloudflare Worker/Vercel 生产版本一致；检查正式目标 URL 实际能访问。
- 生产产物核验：全部 canonical URL、robots allow、有效 Sitemap、无 noindex、真实 404、规范域名 301、子路径末尾斜杠/`index.html` 解析。
- 缓存、WAF、CDN 的改动需最小化，不能只因模拟爬虫失败便放开全部安全规则。
- 若发布失败，保留上一版本，说明进度和错误，不声称成功。

## 站点性能与真实浏览器

- 检查桌面、390px 手机的菜单、第一屏、表单和结果、特殊表格、Print media、分享参数还原。
- Core Web Vitals（LCP/INP/CLS）结合 PageSpeed/CrUX/GSC 真实指标，区分实验室评分与现场用户数据。
- 测试关键外部嵌入：无 JS fallback、网站策略阻断、CSP、CSS 隔离、表单逻辑及移动端。

## SEO 数据阶段

- 接入现有 GSC 与 GA4，不重复已完成的验证或提交。
- 对重要 URL 用 GSC 的真实 URL Inspection/Live Test（有权访问时）；常规 HTTP 或 User-Agent 冒充不能代替 Google 抓取。
- 上线后的内容只按用户问题和 GSC Impressions/Clicks/CTR/Position、SERP 意图及竞争差距扩展。
- 对有价值的行业网站提供可引用工具和文档，鼓励真实、自主、相关的外链。不要强制 dofollow 或保证 Google 会计算链接权重。

## 月度运营评审

1. 受关注的真实页面 / 查询：点击、曝光、CTR、排名、收录。
2. 工具使用：有效计算量、错误率、重置、导出/复制、分享与回流。
3. 技术健康：回归测试、404、速度、移动体验、JS 错误、脚本/缓存兼容。
4. 高价值内容机会：排名 5–20 的词、待完善的页面、可分开的独立意图。
5. 实际外链与分发：已确认来源、相关度、带来的访问、是否自然引用。
6. 下一阶段：P0/P1 修复、最少量高价值新内容与产品增强，指定负责人、验收指标。

严禁将「已提交 Sitemap」「已上线页面」「通过自动化测试」等价成「Google 已收录」「Googlebot 实测通过」「获得外链投票」或「首页排名」。

## V2 扩展 — 冷启动页面质量及商业漏斗

- 发布前独立 URL 审核：页面是否有实际使用入口或原创数据、可见主体 HTML、唯一页面价值、独立 title/H1、规范 canonical、内链和对应 sitemap。
- 结合 GSC 真实自然查询与 `tool_start/tool_success/related_tool_click`，优先优化被使用且存在搜索需求的工具，不以页面数、站外目录提交数做 KPI。
- 定期追踪免费入口 → 深度使用 → 相关工具 → 真实付费的漏斗；若只有引流而无后续任务，不强制套积分模型。
- 所有社区/目录/合作推广记录访问与实际引用。来自目录站的外链不自动等于高质量链接，不保证 Google 会计算。
- 详情参见 `references/growth-and-monetization.md`。


## V2.1 连接器与生产发布闭环

- 操作前先查看当前真实可用连接器与参数 schema，读取当前 commit、部署资源、生产路由和已知稳定版本；不得猜测资源 ID 或把排队中的构建当成成功。
- 尊重用户明确指定的发布通道。若用户要求 Cloudflare 连接器直接部署，不擅自创建/切换 GitHub Actions；也不因已有授权就假设所有账号和资源都可写。
- 生产报告至少包含：commit SHA、实际部署资源/版本、构建结果、路由或自定义域状态、流量分配（若平台提供）、关键正式 URL 的状态和浏览器交互结果。
- 若工具只能验证部署 API，不能执行浏览器测试，需将浏览器验收标为 `NOT RUN` 或 `BLOCKED`，不能写“全站正常”。
- 发布后出现 P0 回归时停止无关改动；如有明确可恢复的稳定版本且回滚不会损害数据，优先恢复并复测。保留故障版本与恢复版本的记录。

## V2.1 AI 搜索可见性实验

- 为每个项目建立固定、覆盖不同意图的用户问题集；在同一平台/产品模式、语言和地区下定期重复测试，并记录日期、回答、提及/链接引用、被引用 URL 与竞争站。
- 至少区分：品牌提及、裸链接、作为证据的引用、流量归因。它们不是同一指标；没有 referral 或平台可用数据时不能推断带来访问。
- 任何结论都注明样本数、窗口和局限。单次回答不能证明平台的固定偏好；不公开的检索/排序机制标为假设，不写成官方规则。
