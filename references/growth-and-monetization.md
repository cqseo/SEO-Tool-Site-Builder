# 上线增长、免费转付费与经济性（G1/G3）

## 获客飞轮

搜索/专业社区/合作方 → 独立任务入口 → 免费完成首个工作 → 可选相关工具/工作流 → 高价值功能与复访 → 用户反馈/分享/自然引用。每一阶段需用实际事件数据验证，不把漏斗设计误认为漏斗已成功。

## 分发策略

- 行业指南、真实可引用数据、免费的嵌入工具和透明方法论，优先于低质量泛目录外链。
- 一次性目录提交须记录是否付费/赞助、最终可见地址、用户相关性和引荐流量；不承诺 PageRank 效果。
- 若针对国家/语言本地化，翻译要准确， hreflang 只能用于实存可访问的等价页。
- 不使用垃圾站群、伪造权威作者、自动生成薄页或买卖操纵链接作为增长策略。

## 最小产品埋点表

| 事件 | 时机 | 禁止上报 |
|---|---|---|
| `tool_start` | 点击开始/提交 | 未脱敏原始文件、地址、客户名称 |
| `tool_success` | 真实输出可见/下载成功 | 个人信息或原始敏感数值 |
| `tool_error` | 可重现的失败分类 | API key、stack 私密字段 |
| `related_tool_click` | 跳转下一个任务 | 完整未过滤 URL 参数 |
| `export_success` | 真实导出完成 | 文件内容 |
| `purchase_success` | 支付平台确认完成 | 卡号、详细支付凭证 |

## 收费的证据门槛

- 广告：有足够自然访问且用户体验允许；不要把想象 RPM 当收入。
- 订阅：有重复性的保存、协作、批量、自动化需求；一次性计算场景不要强制订阅。
- 积分/API：对调用量、重试率、代理采购成本、折扣与毛利进行模拟并记录实际账单。
- B2B/线索：明确客户获取价值、合规与隐私，不能暗中出售用户数据。

利润模拟：`贡献毛利 = 净收入 − 第三方 API − 支付手续费 − 直接按量基础设施 − 退款/失败净损失`。把人工和营销费用在更完整的利润模型中另列。金额仅凭已知报价/账单填写。

- 第 1 个 28 天：检查索引可达性、非品牌曝光、工具成功事件和用户阻碍。
