# G2 — 设计、功能、内容与自动化 QA

## 功能测试矩阵（每个工具分别填写）

| 场景 | 核验 |
|---|---|
| 默认页面 | 初始化后已显示符合原始示例的可信结果，不只是“—” |
| 标准输入 | 对照手算/厂家/公式基线，检验显示值和原始内部计算 |
| 修改输入 | 点击 Calculate 后响应，旧结果及时失效 |
| 单位与模式切换 | 控件可用，隐藏/展示与计算逻辑一致 |
| 边界/错误 | 0、负数、空值、巨大数、非法区间有明确提示 |
| 多区域 | 添加、删除、汇总、取整与单区购买差异合理 |
| 重置 | 回到页面发布时的真实默认输入及结果 |
| Copy | 复制当前数字/前提，不泄露不必要信息 |
| Print | 只输出本次估算单：参数、结果、步骤、来源/免责声明；网页其他 DOM 不打印 |
| Share | 生成 URL fragment；打开后先完整加载功能模块，再回填并提交重新计算；同页多表单选择正确 |
| Embed | 粘贴到独立测试页能工作，脚本失败时来源标识与合理 fallback 不造成问题 |
| 手机 | 390px（另测更窄屏与桌面），无整页横向溢出，键盘和触摸正常 |
| 辅助功能 | label、焦点、aria-expanded、错误与结果通知、可读表格 |

## 计算正确性

- 数学模块独立 UI，可用纯函数测试；保留未四舍五入值用于下游购买数量。
- 先统一量纲（ft/in/yd, m/cm, lb/kg），明确净量/含损耗量、单位与精度。
- 多区域先汇总，再按业务规则取整；材料袋数与订单增量是两个不同概念。
- 价格只用真实用户输入或明示例子；报价不完整时明确显示“不足以计算完整价格”，不得把缺失当作 0。
- 产品厂商规格有版本、日期和适用限制；不得将厂家示例用于未经验证的其他产品。
- 普通材料估算与结构安全判定严格区分。

## 内容与 SEO 审核

- SERP 意图对应内容，不为做页数发布关键词薄页。
- 数学过程可阅读、实用、来源可追溯；独立作者职责诚实透明。
- Canonical 绝对、无 query/hash；实际网页只有一个规范标签。
- 默认使用合适的 schema，不堆砌 FAQPage，也不声称无真实依据的 engineer reviewedBy。
- 主工具页面位于显著位置，文本适度；标题层级、内部链接、图示和移动排版正常。

## P0/P1/P2 分级

- **P0**：计算错误、打印/重置/分享错误、功能不可用、错误索引状态、泄露个人数据、关键子页面 404、发布可能破坏用户资产。上线阻断。
- **P1**：手机溢出、导航不可用、表格差、SEO 关键语义缺失、独立嵌入体验问题；尽量上线前修复，若推迟需记录。
- **P2**：微小间距、可选动画、次要文案、非关键的增强功能；上线后安排。

## 回归原则

复现 → 写可失败的测试 → 定向修复 → 单测 + 预览真实浏览器 → 对照旧用例 → 发布 → 正式站复测。工具“已提供 DOM”不代表按钮“有真实交互”。不得把 `return 200` 冒充完整 JS 功能正常。

## V2 扩展 — 工具矩阵及内容生成 QA

- 共用代码模块更新必须对所有引用该模块的工具做契约回归；动态 slug 配置应校验默认示例、空提示词、空正文、重复 canonical、断开内链。
- 创建独立页前必须记录对应任务和相对现有页面的独特价值；不是只用 AI 改写标题或变量取值。
- PDF/图像/AI 类型工具额外按 `references/platform-and-reuse.md` 检测文件上限、隐私、失败重试、模型计费、下载有效性和接口密钥保护。
- 跨工具状态只传递必要非敏感参数；Analytics 事件使用去识别化信息，不上传原文件及私人参数。
- 当工具、示例、数据来源或正文不能真实落实时，标记“未验证/不可索引”并阻止发布欺骗性页面。


## V2.1 执行级 QA 补充

- 为每个核心工具维护至少 3 类黄金案例：常规输入、边界/非法输入、一个用户真实场景；多区域/费用工具再加组合输入。每例记录单位、规则版本、期望值和允许误差，金额与袋数明确取整策略。
- 浏览器测试必须实际操作表单和控件，并断言结果变化；仅读取 DOM、查找按钮或检查 HTTP 200 不算交互通过。记录 viewport、正式/预览 URL、构建 commit 和实际输出。
- 检查浏览器 console 与关键 network failures；外部脚本被拦截时，验证降级体验而非直接忽略。
- 共享公式/组件变更后，根据依赖关系回归所有使用它的工具页，不只测试当前页面。
- 发布报告的每项测试必须标记 `PASS / FAIL / NOT RUN / BLOCKED`，并附最小可核验的预期/实际值。未运行测试不能因构建成功而标为 PASS。
